# 成员 B：Pre 讲解提纲与答疑

本文件是讲解提纲，不是老师公布的展示页数/时长要求。Part 1 由 A 展示；B 负责 Part 2 和对比分析。正式数值引用 `results/tables/` 的完整结果，不能把 cashew 预检成绩当作六类平均。

## 第 1 页：Part 2 在解决什么

讲法：我们只拿到少量正常产品图，希望检测一张新图是否异常，并标出异常位置。我们使用冻结的 DINOv2 提取局部特征，将正常局部特征组成记忆库，检查新图每个区域离正常记忆有多远。

图示：[可直接在 GitHub 查看方法图](../docs/part2_method_diagram.md)。正常参考图 → 特征提取 → normal memory bank；测试图 → patch features → 最近邻距离 → 异常热力图与整体分数。

要说明：预训练权重来自官方；本阶段没有训练 DINOv2，没有用缺陷标签学习模型。

## 第 2 页：具体方法

1. 按官方方式将 RGB 短边缩放到 448，裁到 14 的倍数。
2. 用 `dinov2_vits14` 提取 patch 特征；一张参考图产生许多局部特征，1-shot 不等于只有一个特征向量。
3. 保留官方 agnostic 的参考旋转与 PCA 前景处理，特征进行 L2 归一化。
4. 每个测试 patch 和全部正常 reference patches 做 k=1 精确近邻。
5. 归一化向量的 squared L2 / 2 对应 cosine distance；距离越大，越不像正常局部。
6. 图像分数取异常距离最高 1% 的均值；patch 图按官方方法上采样和平滑为原图异常图。

注意：我们保留 CPU FAISS 参照，并对 GPU 精确近邻做了数值验证。GPU 后端用 FP32 全量比较，表示相同方法的加速实现，不是新的缺陷学习模型；它不保证与 CPU 逐位相等。报告实际误差及后端，不能只说“完全一样”。

## 第 3 页：实验为什么可信

- 数据：VisA 指定六类，官方 1cls 划分。
- Reference 数：1、2、4、8；seed 0、1、2。按照所检查官方实现的排序分段选图，公开实际名单。
- 每类前 20 张正常训练图仅用于演示阈值校准，在 reference 选择前排除。
- 两个 Part 使用同一个 manifest、相同参考图和测试图；Part 1 接入后再进行正式对比。
- 主指标图像 AUROC，定位指标 pixel AUROC；像素评估包含正常测试图。
- 先每类别计算，再做六类等权平均，最后报告三个 seed 的均值与总体标准差。
- 完整矩阵 72 配置、11,520 次测试预测；额外校准图不混进测试统计。

必须区分：AUROC 用阈值前连续分数；OK/NG 用独立正常校准阈值。显示色标与评估数组分开，彩色图更鲜艳不代表指标更高。

## 常见问题

**为什么没有异常训练图也能检测？** 预训练特征提供通用视觉表示，参考库描述产品的正常局部；测试局部与正常局部差异大时被判为可疑，并非模型预先学过每种缺陷。

**既然 1-shot，为何又有 20 张正常图？** 记忆库只有 1 张 reference 的特征；课程额外允许的 20 张正常图仅设定演示判断阈值，不更新模型/记忆库，AUROC 不使用该阈值。

**为什么 Part 1 可能误报？** 直接像素差容易受位置、姿态和光照影响；具体发生什么应结合 A 的实际结果说明，不能预设所有类别都一定如此。

**为什么图像 AUROC 和像素 AUROC不同？** 一个衡量整张图正常/异常的排序，一个衡量缺陷位置；大面积背景和很少缺陷像素会让定位评价具有不同特点，必须结合真值和失败图分析。

**GPU 数值是否一模一样？** 表示、参考和算法定义相同，但浮点归约顺序可产生微小差异。我们同时给出真实特征误差、完整类别 AUROC 核对和 CPU 后端参照。

**阈值保证误报率 5% 吗？** 不保证。它是 20 张正常校准图的经验第 95 百分位，实际测试分布可能不同。
