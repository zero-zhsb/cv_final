# 期中视频用 PPT

答辩准备：[29 题英文短答与中文追问](qa_prep.md)，以及 [Q&A 速记卡](qa_quick_card.md)。这不是 Canvas 新增的现场答辩要求，也不占用原 4:40 视频时间。

优先打开全量完成版 **`CV_Midterm_FullComparison_Final.pptx`**。共 7 页，16:9；正文英文，备注含中英文讲稿、A/B 分工、建议时间和来源。`speaker_notes_full.md` 为最新备注，`speaker_notes.md` 同步为当前备注，`talk_track_full.md` 为独立双语口播稿。录制时选择一种语言，不必同时读两种。`CV_Midterm_Visual_Final.pptx` 和 `CV_Midterm_4m40s_v2.pptx` 是 Part 1 单配置时期的旧版，仅保留对照，避免混用。

视觉增强版使用深浅页面对照，突出关键分数与 8-shot 六类总体图像 AUROC 相差的 35.82 个百分点。失败页放大官方真值掩码中的三处细小缺陷，并明确标注放大显示。数据、7 页结构和 4:40 时间计划保持一致，原图、异常图均为真实实验输出。

建议配合演示者视图查看备注并录制旁白，按自然语速排练。280 秒是剪辑目标，不是已完成的实测录音时长；导出的视频连同转场必须 ≤5 分钟。可在 3、4 页的已有时间内替换约 5–10 秒实际运行录屏，操作命令见 `../midterm_video/recording_steps.md`。

文字、流程图、比较表和趋势图均为可编辑对象；产品图和热力图保留为真实实验图像。静态结果不冒充新推理，两种方法的分数范围和色标分别解释。第 3/4 页是 cashew/1-shot/seed=0 示例；第 5 页为 8-shot 六类总体比较，第 6 页为两方法的完整 few-shot 曲线。

Part 3 计划已按课程要求调整为 **固定输入 448、冻结 DINOv2，融合多个层级的特征**，与不变的 Part 2 做相同参考图、seed、预处理及评价的对照。它属于尚未验证的计划，不宣称已经取得提升。旧素材包的多图像尺度方案属于候选方向，本次 PPT 优先采用多层融合方案。两套基线已经完成，不再把补齐 Part 1 写成未来工作。

本 PPT 没有嵌入真人录音或操作视频。录制前由两位成员补充需要的姓名等身份信息，并确认讲稿与各自贡献准确。
