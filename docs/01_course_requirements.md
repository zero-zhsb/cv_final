# 课程要求与当前范围

## 依据及边界

依据用户提供的 `Project_2__Few_Shot_Industrial_Visual_Anomaly_Detection.pdf`（5 页）。文件本身不上传到公开仓库。以下“必做/可选”是课程要求的转述；具体目录、人员分配、六天日程及 Part 1 公式属于团队实施建议。

PDF 没有单列 Pre 的时长、进度门槛或评分权重。用户补充了“Pre 必须展示 Part 1”，本阶段据此优先完成 Part 1、Part 2。后续若 Canvas 有单独 rubric，应更新本文件。

## Part 1 必做（PDF 第 3 页）

1. 使用与 AnomalyDINO 相同的正常参考图、相同分辨率，和最近模板比较。
2. 用 RGB/灰度绝对差、SSIM 差异、梯度或局部纹理等产生异常图；结合平滑、形态学处理解释异常区域。
3. 每类正常训练图按文件名排序，取前 20 张作为演示校准图，在所有参考图选择前排除。
4. 使用校准图的图像分数第 95 百分位作为演示 OK/NG 阈值。这些额外正常图仅用于演示校准，不进入记忆库、不用于拟合模型。
5. 分析模板法何时把姿态、背景、光照变化误认为缺陷。

配准（ECC/特征匹配）与卷积自编码器是可选项。RGB 差分、sigma=1、top-1% 均值是本仓库建议的初版实现，不是老师指定的公式。

## Part 2 必做（PDF 第 3–4 页）

1. 使用官方 AnomalyDINO，冻结 DINOv2 特征；模型 `dinov2_vits14`，分辨率参数 448，`agnostic` 预处理。
2. 正常参考图数 1、2、4、8；seed 0、1、2。保存参考图名单，并让基线与改进复用。
3. 构建正常 patch 记忆库，用近邻距离输出图像分数和像素异常图。
4. 数据仅要求 VisA 的 candle、capsules、cashew、chewinggum、fryum、pipe_fryum，使用官方 `1cls` 划分与完整测试图/掩码。
5. 报告规定的指标、few-shot 稳定性、时间和显存。AnomalyCLIP 是可选项，不要求训练基础模型。

## 指标与公平比较（PDF 第 2、4 页）

- 图像 AUROC 是主指标：使用阈值前的连续图像分数；逐类别及六类等权平均。
- 像素 AUROC：包含正常测试图（全零掩码），逐类别计算后六类等权平均。
- 每种 shot 报告 seed 0/1/2 的均值与标准差；本仓库约定 std 的 `ddof=0`，报告注明。
- 同一设备记录推理时间、峰值 GPU 显存、输入大小、是否含特征提取及所有测试时处理。
- 用真实的困难案例展示原图、真值、热力图；要求五个代表性困难示例，解释实际错误，不制造失败。
- 参数选择不能使用测试标签。禁止为 AUROC 对每张测试图单独归一化。
- AP、AUPRO 可选；若报告 AUPRO，上限使用官方 FPR=0.30。

## 最终项目要求，后续仍需完成

- Part 3：选择一个有理由的改进，与不变的 Part 2 比较；无提升时用受控实验和失败分析解释。完全忽略 Part 3 会被判 Incomplete。
- CVPR 格式 6–8 页报告，不含参考文献；包含方法、定量/定性实验、消融和失败分析。摘要末尾放公开 GitHub 链接，覆盖推荐阅读清单的引用。
- 公开仓库及完整 README：依赖、数据、权重、训练/评估说明及代表性结果。本项目必做路线无需训练，应明确写“仅推理”。
- 可运行 demo 或录屏：产品图输入、异常分数、OK/NG、像素热力图；视频与代表输出打包 `anomaly_demo.zip`。
- arXiv、全 12 类数据评估、AnomalyCLIP 为可选；扩大数据集不是高分必要条件。

文件强调改进的理由和原创性、实测结果、实验分析与清楚的可视化，没有给出百分比分值表或保证最高分的数值门槛。
